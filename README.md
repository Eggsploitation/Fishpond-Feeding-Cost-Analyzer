# Fishpond Feeding Cost Analyzer

A Python program that estimates fish biomass,
daily feed requirements, total feed consumption,
and feeding costs over a culture period.

## Requirements
- Python 3.12 or newer
- NumPy
- Matplotlib

## How to Run

Install the required libraries:

pip install -r requirements.txt

Run the program:

python main.py

Sample Input 
Number of fish stocked: 1000
Initial average fish weight (grams): 100
Assumed daily weight gain per fish (grams): 1
Daily feeding rate (%): 3
Culture period (days): 30
Feed price per kilogram (PHP): 85
